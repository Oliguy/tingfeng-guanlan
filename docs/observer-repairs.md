# 分类、收盘标记与历史行情

异动分类读取经营事实及已冻结分类资料。移动数据库时，应同时维护配置中的 `paths.classification_root`，指向保存 `root_current.json`、`current.json` 及其引用快照的目录。默认位置为经营事实库同级的 `classification_working`。资料按既有哈希检查，不会因行情更新自动重新分类；缺少经营依据的新增股票保留待归类。

异动列表的收盘标记显示截至所选日最近20个开市日的涨停序列，例如 `3天2板`、`1天1板` 或 `近20天1板`。最近没有确认涨停时留空。存在未知交易日时也不显示确定的板数；逐日状态保留在查询结果的 `limit_sequence.days`。判定使用原始收盘、前收盘参考价、价格最小单位、市场制度、上市日期及日期ST事实，并优先核对已有日期限制价。没有题材的股票不再显示题材占位。

主板ST及*ST股票的制度切换按日期处理：2026年7月6日起涨跌幅限制为10%，此前必须结合当日风险警示事实判断5%或10%。依据见[上交所2026年交易规则修订说明](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20260424_10816474.shtml)、[深交所2026年交易规则发布通知](https://investor.szse.cn/lawrules/rule/trade/t20260424_620190.html)。创业板2020年8月24日前后的限制比例分别处理，旧制新股上市阶段缺依据时保留未知。

首页“补齐数据”直接提交全部更新；右侧箭头可选择股票与市场指数、ETF、行业与题材、涨跌停日期证据、指标或证券名称。任务状态仍可在各栏目查看，写入操作集中在首页。统一更新对真实来源进行采集，浏览及画图本身只读。ETF历史补采可在首页数据详情的更新状态中输入ETF代码及日期范围。

个股图读取所选截止日前全部已有本地行情，点击图表的“全部”可查看全部历史。初始可见根数仍按看图设置，不等同于接口提供的历史范围。行业及题材集合图只展示已经发布的真实指数范围；集合成员个股的历史不受集合一年范围限制。缺行情或缺复权因子的日期保留缺口，可切换原始价格检查。

ETF的日周线按实际已存日行情只读计算。如果行业没有当月正式代表ETF，则从当前有效映射且有行情的ETF中选择报价日期最新、当日成交额较大的对象，标注“映射ETF”。这是具体ETF的行情，并非新发布的行业组合或正式月度龙头。组合结果过期的提示保留，首页补齐可以重建派生结果。
