# 设置与配置文件

从任意栏目右上角点击 **设置**。六个栏目使用相同的四个分类；Esc 关闭设置，方向键可在分类间切换。

| 分类 | 常用选项 | 生效时间 |
|---|---|---|
| 显示 | 字号、舒适或紧凑密度、减少动画、启动栏目 | 显示即时生效，启动栏目下次打开使用 |
| 看图 | 滚轮缩放、切换对象快捷键、默认周期、价格、K线根数、量能、辅助线与线宽 | 即时生效；默认视图用于没有单独保存视图的对象 |
| 数据引用 | 本机总数据目录、用户状态目录、训练库，或远端服务地址和令牌环境变量名 | 检查通过后保存，重启服务后生效 |
| 配置管理 | 查看文件位置、导出、导入、重新读取 | 显示导入后即时生效，引用重启生效 |

设置面板会显示“已保存”或保存失败的原因。显示和看图修改自动保存；数据引用需要点击 **保存数据引用**。数据输入未保存时，修改显示设置不会把这些地址一并保存。恢复默认显示或看图只恢复对应选项。

## 文件位置和恢复

配置管理中显示当前使用的完整文件位置。`serve --config guanlan.json` 默认保存到同目录的 `guanlan.settings.json`，原来的 `guanlan.json` 不会被重写。也可在主配置的 `server.settings_file` 指定相对于主配置的文件地址，或用环境变量 `GUANLAN_SETTINGS_FILE` 指定其他文件。

`connect` 默认使用 Windows 的 `%LOCALAPPDATA%/TingFengGuanLan/connection.settings.json`，其他系统默认使用 `~/.config/TingFengGuanLan/connection.settings.json`。多个独立连接可分别指定文件：

```sh
guanlan connect --url https://guanlan.example.com --settings-file ./connection.settings.json --open
```

文件采用 `guanlan.settings.v1` JSON 格式，保存 `preferences`、`data` 和保存时间。重启或清空浏览器缓存后，以该文件恢复设置。首次使用且文件没有保存偏好时，将当前浏览器已有的看图设置迁入文件；已有文件优先于浏览器缓存。设置属于当前服务或本机连接实例，六个栏目共用。

保存采用文件锁、版本检查与原子替换。另一个窗口已先保存时，本次修改不会直接覆盖它；重新读取后可重试自己的修改。写入失败保留原文件和待保存修改，修复目录权限后点击重试。

配置损坏时会提示并使用默认值，普通修改不会静默覆盖坏文件。通过导入正确配置恢复时，保留一份损坏的小型配置文件用于排查；这不涉及数据库备份。

## 本机数据引用

选择 **本机数据库**，填写绝对路径，再点击 **检查引用**。总目录应符合 [数据系统归集](数据系统归集.md) 的角色映射；旧布局也支持对应的经营事实、行情、证券状态、ETF及行业发布文件。检查会确认这些源库存在且可只读打开，不会创建缺失数据库。

用户状态目录应与源数据文件分开，训练数据库必须位于用户状态目录中。选择原来的训练库即可继续已有记录。改地址只改变程序下一次启动读取的来源，不会迁移、复制、删除行情或训练记录，也不会改动数据采集任务的配置。

保存后会同时显示 **当前生效** 和 **已保存、等待重启** 的状态。关闭服务并重新启动后新引用才生效；仍在运行的进程继续使用原引用，避免一次操作混用两套来源。

## 远端服务与换电脑

选择 **远端听风观澜服务**，填写 HTTPS 服务地址，以及令牌的环境变量名，例如 `GUANLAN_ACCESS_TOKEN`。启动程序前设置该变量的值：

```powershell
$env:GUANLAN_ACCESS_TOKEN = '<服务管理员提供的令牌>'
```

只保存环境变量名，配置文件不会保存令牌值。普通 HTTP 仅允许本机地址，用于本机服务或 SSH 隧道。点击检查会验证服务身份和 API 版本；保存后重启使用新服务。`connect` 入口用于远端连接；要在本机直接使用数据库，应使用 `serve --config`。

在其他电脑导入导出的 JSON 后，重新检查引用：本机绝对路径可能需要修改，远端连接则需要在新电脑设置对应的令牌环境变量。训练与题材状态仍由所连接的数据宿主管理。数据引用修改仅允许数据宿主或本机连接端进行，直接访问远端服务的浏览器不能改宿主的数据库地址。

导出仅包含已保存的设置，不包含行情、训练数据或访问令牌值；配置中的地址可能属于你的环境，分享前请核对。完整部署方式见 [部署与连接](deployment.md)。
