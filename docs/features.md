# 功能与准备条件

| 能力 | 界面 / 功能是否保留 | 数据与运行条件 |
|---|---|---|
| 市场总览 | 保留 | 各源库可分别缺失，页面显示覆盖和未知状态 |
| 30 行业与细分板块 | 保留 | 分类、已发布集合、支持证据、共享指标 |
| ETF 分组、代表 ETF、持仓和图表 | 保留 | 兼容 ETF 3/4 库及股票、日历、共享指标 |
| 题材目录、预览、保存、归档恢复 | 保留 | 独立可写题材状态，或原数据所有者服务 |
| 题材应用、集合指数重算 | 保留操作入口与原任务合同 | 必须连接对应数据的更新提供者 |
| 异动日期、名单、股票图表 | 保留 | 股票原始行情；分类/限价缺失单独标记 |
| 龙头评分与详情 | 保留 | 行情、日历与必要分类/限价证据 |
| K 线训练、资金衔接、复盘、笔记 | 保留 | 股票、因子、历史状态；独立训练数据库 |
| 日周月图表、详情、看图偏好 | 保留 | 页面共享设置；偏好保存在浏览器 |
| 股票/ETF 更新与补采、日历、指标重算 | 保留适配 | 原 StockOperator/天工坊等生产服务及其授权 |
| 跨电脑查询和操作 | 新增 | 同一认证 API，可用浏览器或 Python 客户端 |
| 数据库兼容检查 | 新增 | 元数据只读，检查与修复分离 |

便携包不复制数据生产者，不包含源端账号或密钥。未配置提供者就不能执行采集或重算；该限制会明确返回，不能以按钮存在当作更新成功。一个提供者的题材/行情/结果必须对应当前读取的数据，不支持隐式跨库同步。

各计算、查询和训练组件的继承回归使用合成数据。真实数据的缺失继续保留；例如 ETF 缺周线不会在浏览或验收中自动生成。首次加载和暖加载应分别测量，接口成功不代表在任意机器都达到相同耗时。
