# 2.0.0 分层审计与验证（历史记录）

审计日期：2026-10-09。目标是保留六栏目及其业务语义，让界面、功能和数据可以分别维护、部署和连接。

## 职责调整

原实现依赖安装路径发现、固定工作区配置和本机业务包，页面入口与业务分派绑定。现在界面包只包含页面、图表、传输及桌面窗口适配；应用包负责认证、API、用例和外部任务适配；数据包负责配置、SQL、数据库合同和仓储。纯计算放在 domain 包，属于功能层。

仓储不导入应用或界面，纯计算不导入仓储，界面不导入数据或应用。应用中的训练 SQL 已移入命名仓储语句。阅读入口不导入 StockOperator，不扫描其他项目安装目录。继承代码中未被六栏目使用的旧独立 HTML 导出/自动更新脚本不进入便携发行；数据生产仍由显式提供者执行。

数据库仍采用既有 SQLite 消费结构，新增角色、字段、类型亲和性、主键、版本和单位合同。原市场、分类和计算源只读；新训练及题材状态有独立写入边界。未对真实原库做复制、迁移、索引、修复或更新。

跨电脑访问使用认证 API。浏览器、独立本机连接入口、Python 客户端共用请求合同；数据库文件只由数据宿主本地访问。更新请求保留原 request_id 和提供者任务身份，网络回执不明时不自动重提。
